# 災観 SAIKAN

**日本の衛星・防災情報と現地報告を統合する、災害救助・避難判断支援PWA**

- **公開Web:** https://akinomizuki.github.io/saikan-map/
- **Repository:** https://github.com/AkinoMizuki/saikan-map

> 地図にない障害を記録し、危険を避けて避難・救助ルートを再構成する。

現在の版は **ver 0.3.2** です。

## 目的

SAIKANは衛星画像を見るためだけのビューアではありません。地域住民、避難支援者、災害救助隊、現地支援者、対策本部が、現在の状況を把握して次の行動を判断するための共通状況図です。

- 地域住民・支援者：現在地から到達可能な避難候補と危険回避ルートを確認
- 災害救助隊：救助目的地への進入ルート、道路閉塞、要救助区域を確認
- 対策本部：衛星・防災更新、現地報告、道路網、共有情報をまとめて確認

## 利用モードと機能分離

上部の3ボタンは単なる表示切替ではなく、**利用者ごとに必要な機能だけを表示するモード切替**です。選択したモードは端末へ保存され、次回起動時にも復元されます。

| モード | 主な利用者 | 表示する中心機能 | 隠す機能 |
|---|---|---|---|
| **避難する** | 地域住民・避難支援者 | 現在地、避難候補、徒歩・車椅子経路、危険・通行不能報告、QR共有、オフライン準備 | 救助目的地、救助車両、衛星解析操作、詳細レイヤー、破壊的なデータ管理 |
| **救助・支援する** | 消防・警察・自衛隊・DMAT・現地支援者 | 救助目的地、徒歩・車椅子・救助車両の進入路、道路閉塞、要救助区域、衛星・防災更新、QR共有、印刷 | 完全初期化などの対策本部向け管理 |
| **対策本部** | 災害対策本部・現地指揮所 | 衛星・防災更新、全現地報告、QR共有・結合、状況図印刷、表示レイヤー、キャッシュ・データ管理 | 個人向け避難候補計算、救助目的地指定 |

選択中のモードは「現在の判断」欄にも説明されます。モードを切り替えると、前モードの経路選択は解除され、誤って別用途の経路を引き継がないようにします。

- ALOS-2、QZSS、ひまわり・気象庁などの更新状態表示
- Service Worker、IndexedDB、永続ストレージによるオフライン継続利用
- キャッシュ、地域、道路、観測更新、現地報告の削除・完全初期化

## 基本的な使い方

### 避難する

1. 上部で「避難する」を選択
2. 地域パックを保存して選択
3. オンライン中に「OSM道路網を保存」
4. 「現在地を出発点」または「地図で出発点」
5. 災害種別と、徒歩または車椅子を選択
6. 「避難先と安全な経路を探す」
7. 現地で確認した通行不能や危険を地点・線・エリアで報告
8. 経路を再計算

### 救助・支援する

1. 上部で「救助・支援する」を選択
2. 地域・道路網を準備
3. 救助隊の出発点を指定
4. 地図上で救助目的地を指定
5. 徒歩、車椅子または救助車両を選択
6. 「救助目的地への進入ルートを計算」
7. 道路閉塞、橋梁異常、要救助区域を記録して再計算
8. 必要に応じてQR、GeoJSON、印刷で共有

### 対策本部

1. 上部で「対策本部」を選択
2. ALOS-2等の衛星・防災更新を確認
3. 各端末から受領したQRまたはGeoJSONを結合
4. 全現地報告、重大報告、道路網、更新時刻を確認
5. 状況図とQRを印刷
6. 必要時だけ管理・削除機能を使用

## QR分割オフライン共有

通信や本部DBへ接続できない場合でも、端末に保存した現地障害・要救助・安全確認報告をQRで受け渡せます。

```text
端末Aで報告を記録
    ↓
QR共有を作成
    ↓
GZIP圧縮・SHA-256付与
    ↓
容量に応じて複数QRへ分割
    ↓
端末Bで全QRを順不同に読込
    ↓
SHA-256検証・復元
    ↓
ID・revision・更新日時で結合
    ↓
地図とルート判定へ反映
```

共有コード形式：

```text
SAIKAN1|共有ID|分割番号|総数|圧縮方式|SHA-256短縮値|分割データ
```

- 受信途中の分割データはブラウザ内へ一時保存されます。
- 同じQRを複数回読み込んでも重複登録しません。
- 同じ報告IDでは、`revision`が大きいものを優先します。
- `revision`が同じ場合は更新日時が新しいものを優先します。
- QR画像ファイルの直接読取はブラウザの`BarcodeDetector`対応状況に依存します。
- 非対応ブラウザではQR読取アプリで文字列を取得し、共有コード欄へ貼り付けます。
- 大量の報告はGeoJSONファイル共有または将来のSAIKAN Hub同期を優先してください。

QR生成にはMIT Licenseの`davidshimjs/qrcodejs`を固定コミットからPagesビルド時に取得し、SAIKAN配下から自己配信します。実行時は外部CDNへ依存しません。

## 印刷

「現在の状況図・報告一覧を印刷」では、次をA4横向けの印刷資料として出力します。

- 対象地域と利用モード
- 印刷日時
- 現在の判断
- 基礎データ、道路網、衛星・防災更新、現地報告の鮮度
- ALOS-2、QZSS、気象更新状態
- 表示中の避難・救助ルート
- 現在の地図画像
- 現地障害・報告一覧
- 安全上の注意とクレジット

OSM背景画像のCORS状態によってCanvasを印刷画像へ変換できない場合は、判断・報告一覧を印刷し、地図は画面のスクリーンショットを併用します。

「QR全枚を印刷」では、分割QRを1ページずつ番号、総数、共有ID付きで印刷します。

## 地図記号

| 表示 | 意味 |
|---|---|
| 緑色の点 | 出発点・現在地 |
| 青色の点 | 指定緊急避難場所・避難候補 |
| 紫色の点 | 救助目的地 |
| 青色の線 | 推奨避難・救助ルート |
| 赤・橙色の地点／線／エリア | 道路閉塞、浸水、土砂、火災などの現地障害 |

避難候補の青色点には施設名を地図上へ表示します。

## 熊本地震のALOS-2速報図

JAXA防災インタフェースの災害ID `2026-00024-JPN` を観測更新カタログへ登録しています。

https://daichi-bousai.dpif.jaxa.jp/externalif/disaster/2026-00024-JPN/

登録済み速報図：

- ALOS-2 Path 124 / Frame 680 / HH
  - 発災前：2025-08-12 14:30:27 UTC
  - 発災後：2026-07-28 14:30:28 UTC
  - 解析：変化域抽出・RGB合成
- ALOS-2 Path 124 / Frame 690 / HH
  - 発災前：2025-08-12 14:30:35 UTC
  - 発災後：2026-07-28 14:30:36 UTC
  - 解析：変化域抽出・RGB合成

これらはJAXA公開の**災害速報図・ブラウズ画像**です。広域状況の目視確認には使えますが、画像単体には正確な地理参照境界がないため、道路閉塞を自動確定する入力にはしません。

GeoTIFF、WMS、GeoJSON等の地理参照済み解析結果が得られた場合は「更新ファイル読込」から取り込み、危険区域としてルート計算へ反映できます。

## データの扱い

### 経路判定へ直接使用するもの

- 保存済みOpenStreetMap道路網
- 地域パック内の危険区域
- 地理参照済み観測・被害GeoJSON
- 現地で記録した地点・線・エリア障害
- 検証・結合済みのQR共有報告

### 参考表示に留めるもの

- 地理参照境界がない衛星ブラウズ画像
- 未確認のSNS情報
- 観測日時や解析条件が不明な画像

速報画像だけを根拠に道路や建物の被害を確定しません。

## オフライン利用

事前保存後は、通信断時にも次を使用できます。

- 地域パック
- 保存済み道路網
- 避難所・建物・危険区域
- 地理参照済み観測更新
- 現地障害・要救助区域
- 避難・救助ルート計算
- QR分割共有の作成・結合
- GeoJSON状況データの書出し・読込
- 状況図とQRの印刷

OpenStreetMap標準背景タイル、Overpass API、JAXA・気象庁等からの新規更新取得は通信が必要です。

## 注意

- SAIKANの推奨は自動判定であり、安全を保証するものではありません。
- 自治体、警察、消防、救助隊、気象庁等の公的指示を優先してください。
- 避難所の開設状況、収容状況、施設被害は別途確認が必要です。
- 衛星速報図と現地報告は、取得・確認時刻を必ず確認してください。
- OSM道路網は現実の通行可否を保証しません。現地障害を随時記録してください。
- QRの受信データは改ざん検出を行いますが、報告者の身元を証明する電子署名ではありません。
- 現場運用では報告の確認状態、報告者、所属、確認者をSAIKAN Hubで管理する構成が必要です。
