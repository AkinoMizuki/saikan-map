# 災観 SAIKAN

**オフライン3D災害状況マップ / Offline 3D Disaster Situation Map**

- **公開Web（GitHub Pages）:** https://akinomizuki.github.io/saikan-map/
- **GitHubリポジトリ:** https://github.com/AkinoMizuki/saikan-map

> 災害前後を、通信がなくても見比べる。

無料・静的・オフライン優先の災害状況マップPWAです。全国の地域パック、OpenStreetMap背景、ALOS-2/PALSAR-2の表示用衛星レイヤー、避難所、建物、危険領域、現地調査記録を重ねて表示します。

現在の版は **ver 0.2.0** です。

## 主な機能

- 全国対応の地域パックカタログ
- 地域パックのダウンロード、端末ファイル読込、URL読込
- OpenStreetMap標準タイルによるオンライン背景地図
- 左ドラッグによる地図移動
- 右ドラッグまたは `Shift` + ドラッグによる方位・傾斜回転
- 2D／疑似3D切替、北向きリセット、方位表示
- 建物ポリゴンの高さ押し出し表示
- 災害前後比較スライダー
- 危険領域、道路、避難所、気象情報の重畳
- ALOS-2表示用レイヤーのダウンロード、SHA-256検証、端末保存、透明度調整
- GNSS現在地表示
- 現地調査記録の保存とGeoJSON入出力
- Service Workerによるアプリ本体のオフライン保存
- IndexedDBによる地域パック、ALOS-2レイヤー、調査記録の保存
- キャッシュ消去、個別削除、全削除、完全初期化
- クレジットの画面下部常時表示
- 外部APIキー、従量課金、広告、アクセス解析なし

## 操作方法

### 地域パック

1. 「ダウンロード可能な地域パック」から地域を選択します。
2. 「選択地域をダウンロード」を押します。
3. SHA-256検証後、端末のIndexedDBへ保存されます。
4. 「端末に保存済みの地域パック」から表示対象を切り替えます。

現在のカタログには熊本県嘉島町の基礎防災パックと架空訓練パックが登録されています。嘉島町専用アプリではなく、`data/catalog.json` へ追加することで全国の地域パックを扱えます。

### 地図操作

| 操作 | 動作 |
|---|---|
| 左ドラッグ | 地図移動 |
| マウスホイール | 拡大・縮小 |
| 右ドラッグ | 方位と傾斜を回転 |
| `Shift` + 左ドラッグ | 方位と傾斜を回転 |
| `3D` / `2D` | 傾斜表示を切替 |
| `N` | 北を上へ戻す |
| `⌂` | 選択地域全体を表示 |

## OpenStreetMap背景

OpenStreetMap標準タイルは、位置を把握するための**オンライン背景地図**として使用します。

- 画面下部に `© OpenStreetMap contributors` を常時表示します。
- 標準タイルサーバーの大量事前取得やオフライン一括保存は行いません。
- 通信断時に使う背景地図、道路、建物等は地域パックへ格納します。
- OSM由来データを地域パックへ入れる場合は、ODbLに従って出典を記載します。

## ALOS-2データの取得と反映

画面の「ALOS-2衛星レイヤー」から、カタログへ登録済みの表示用プロダクトを取得できます。

```text
ALOS-2表示用カタログ
    ↓
画像レイヤーをダウンロード
    ↓
SHA-256検証
    ↓
IndexedDBへ保存
    ↓
緯度経度範囲に合わせて地図へ重畳
```

JAXAが配布するL1.1 CEOSやL2.1 GeoTIFFの原データは、容量と処理負荷が大きいためブラウザ内では直接解析しません。外部PCで位置確認、輝度調整、切り出し、PNG/WebP変換を行い、`data/alos2/catalog.json` へ登録します。

カタログに表示用レイヤーが未登録の場合、「ALOS-2公開状況を確認」ボタンとしてJAXAの公式公開ページを開きます。公開されていない観測データや未作成の被害解析結果を推定表示しません。

詳細は [`data/alos2/README.md`](data/alos2/README.md) を参照してください。

## オフライン利用

1. オンライン状態でアプリを開きます。
2. 必要な地域パックをダウンロードします。
3. 必要なALOS-2表示用レイヤーをダウンロードします。
4. 「永続保存を要求」を押します。
5. 「完全オフライン検証」を実行します。
6. 機内モードで再起動・地図表示・記録保存を実地確認します。

オフライン時には、端末へ保存済みの地域パック、ALOS-2レイヤー、現地調査記録を表示できます。OpenStreetMap標準タイル、最新の気象情報、最新の道路規制、未取得の衛星データは更新されません。

ブラウザ内保存は利用者によるサイトデータ削除や端末管理ポリシーの影響を受けます。災害用途では `.dmap` 原本や衛星レイヤーをSDカード、USBメモリ、外付けストレージ等にも保管してください。

## キャッシュ・データ削除

| 操作 | アプリキャッシュ | 地域パック | ALOS-2 | 調査記録 | 設定 |
|---|---:|---:|---:|---:|---:|
| アプリキャッシュを消去 | 削除 | 保持 | 保持 | 保持 | 保持 |
| 選択中パックを削除 | 保持 | 選択中のみ | 保持 | 関連記録も削除 | 一部更新 |
| 全地域パックを削除 | 保持 | 全削除 | 保持 | 保持 | 選択解除 |
| 保存済みALOS-2を削除 | 保持 | 保持 | 全削除 | 保持 | 保持 |
| 全調査記録を削除 | 保持 | 保持 | 保持 | 全削除 | 保持 |
| アプリを完全初期化 | 削除 | 全削除 | 全削除 | 全削除 | 全削除 |

完全初期化では誤操作防止のため `RESET` の入力が必要です。

## 地域パックの作成

```bash
python3 tools/build_region_pack.py \
  data/source/training-sample \
  data/packs/training-sample.dmap \
  --write-json
```

検証：

```bash
python3 tools/validate_region_pack.py data/packs/training-sample.dmap
```

詳細は [`docs/PACK_FORMAT.md`](docs/PACK_FORMAT.md) を参照してください。

## 実データ処理の推奨構成

```text
ALOS / ALOS-2 / 航空写真 / ドローン
    ↓ 外部PCで位置補正・変化解析・Web表示用変換
衛星画像レイヤー / 危険領域GeoJSON

PLATEAU / OpenStreetMap / 基盤地図情報
    ↓ 地域単位で切出し・属性整理
建物・道路・避難所GeoJSON

気象庁防災情報XML / 観測データ
    ↓ スナップショット化
気象GeoJSON

各データ
    ↓ 地域パックまたはALOS-2カタログへ登録
端末へダウンロード
    ↓
完全オフライン利用
```

衛星変化やSAR差分だけで建物被害を確定しません。現地確認、公的情報、航空写真、ドローン、複数時期の観測結果と併用してください。

## GitHub Pages

`main` ブランチへpushすると、GitHub ActionsがGitHub Pagesへ配備します。

初回のみ、GitHubの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。

ローカル確認ではService Workerを動かすためHTTPサーバーを使用します。

```bash
python3 -m http.server 8000
```

```text
http://localhost:8000/
```
